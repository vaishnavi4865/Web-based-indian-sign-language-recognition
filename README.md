A web-based application that helps deaf and mute individuals communicate in real time using Indian Sign Language (ISL) recognition.
Features
Real-time gesture recognition using a webcam
MediaPipe-based hand, face, and body landmark detection
CNN-LSTM model for gesture recognition
NLP-based sentence formation
Emotion recognition
Text-to-Speech (TTS) conversion
User-friendly and low-cost web platform
Technologies Used
Python
Flask
OpenCV
MediaPipe
TensorFlow/Keras
NLP (NLTK/SpaCy)
gTTS/pyttsx3
